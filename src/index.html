Data Harga & Katalog Layanan

Update online otomatis (tanpa skrip, tanpa kredensial)

Satu klik mengambil harga & katalog terbaru langsung dari sumber publik: AWS Price List API resmi, daftar harga Google Cloud (pricing.yml yang dibangkitkan harian dari Cloud Billing Catalog API), dan kurs USD→IDR. Butuh koneksi internet.


      

      
Alternatif: skrip Python (tools/update_prices.py)
        
Untuk otomasi terjadwal di server, jalankan tools/update_prices.py lalu impor prices.json dengan tombol di atas.

      

    

    
Semua sel di bawah bisa diedit langsung. Perubahan tersimpan otomatis di browser ini dan dipakai pada perhitungan berikutnya. Harga dalam USD, basis region US; region lain memakai pengali.

  

  







  

    
Ekspor Laporan

    
Laporan memuat profil kebutuhan, solusi, topologi, rincian biaya, proyeksi 12 bulan, TCO, dan catatan. Semua dibuat di browser Anda, tanpa internet.

    

      
      
      
    

    

  







  

    
Backup & Restore Data Analisis

    
Backup berisi seluruh input kebutuhan, data harga yang dipakai (termasuk hasil update/edit), pengaturan mata uang & kurs, serta bahasa. Hasil perhitungan dibuat ulang otomatis saat data dipulihkan.

    

      

        
File backup (.json)

        
Simpan ke komputer Anda dan pulihkan kapan saja.

        

          
          
        

      

      

        
Backup di server

        
Tersimpan di akun Anda dan bisa dipulihkan dari perangkat lain.

        

          
          
        

      

    

    

    

  

  

    
Proyek (input saja)

    
Simpan atau muat input kebutuhan saja. Kompatibel dengan file proyek versi sebelumnya.

    

      
      
    

  







  

    
Mata Uang & Kurs

    
Harga cloud bersumber dalam USD, sedangkan asumsi on-premise mengikuti mata uang data yang Anda masukkan. Pilih mata uang output: seluruh perhitungan, tabel, grafik, dan file ekspor otomatis dikonversi.
